BDA400 Assignment 2 - Technical Analysis using R, Preliminary Stage

Files:
- portfolio.txt: stock symbols, one per line.
- technical_analysis.R: functions to download stock data, calculate statistics, display data, and create charts.
- NavjotSingh_BDA400_A02.docx: assignment report with screenshot locations and documentation.

How to run:
1. Install R and RStudio.
2. Open the Assignment2 folder as your working directory in RStudio.
3. Run install.packages(c("quantmod", "TTR")) once.
4. Open technical_analysis.R and run the script.
5. Internet access is required because quantmod downloads market data from Yahoo Finance.
6. Capture the required screenshots and place them into the report where marked.
